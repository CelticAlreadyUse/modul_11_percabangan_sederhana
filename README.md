# Modul 11: Percabangan Sederhana

Kumpulan latihan Java untuk mempelajari operator perbandingan serta percabangan
`if`, `else if`, dan `else`.

## Daftar program

- `percabangan.java`: contoh operator perbandingan dan logika.
- `GanjilGenapChecker.java`: menentukan bilangan ganjil atau genap.
- `AgeChecker.java`: membandingkan umur dua orang.
- `IdealWeight.java`: mengecek berat badan berdasarkan selisih tinggi dan berat.
- `ItemDIscount.java`: menampilkan produk dan menerima pilihan barang.

## Menjalankan program

Proyek ini membutuhkan Java 17 dan Maven.

```bash
mvn compile
java -cp target/classes percabangan.GanjilGenapChecker
```

Ganti `GanjilGenapChecker` dengan nama kelas lain yang ingin dijalankan.
